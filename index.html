Write a preset as text
How to write it

One setting = value per line. Capitals, spaces and units are optional; # starts a comment. Lines you leave out are off or default.

Piano                    # a first line naming a preset starts from it
Name = My piano          # or name it without starting from a preset
Base = Piano             # or say which preset to start from
Oscillator = saw         # sine, square, saw, triangle or custom
Harmonics = 1, .5, .3    # custom shape; also saw, square, triangle, 1/n^1.7, odd 1/n
End harmonics = 1/n^3    # shape at the end of each note
Morph = 1.2s             # how long the change takes (or off)
Layer 1 = octave down, 45%, +3ct
Layer 2 = +7, 30%        # semitones work too
Unison = 3, 12ct         # voices, spread (or off)
Attack = 3ms             # also Decay, Sustain, Release
Drive = off
Filter = on
F reso = 1               # short names: F, Dr, Ch, Fl, Ph, Dly, Verb
F cutoff = 2500          # Hz; 2.5k works too
Verb mix = 20%           # setting a knob turns its pedal on

Pedals and their knobs:

Layers

Stack extra copies of the oscillator on every note, at an octave or a fifth away. Unison adds slightly detuned copies spread left and right for a thicker sound.

Wave maker

Draw one cycle of a wave, or drag the harmonic bars (1 = the note itself, 2 = an octave up, and so on). Give it a different end of note shape and every note morphs from one to the other, the way a piano starts bright and mellows. Editing switches the oscillator to Custom.
